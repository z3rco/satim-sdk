# Support

## Where to get help

| Channel | Use for |
|---|---|
| [GitHub Discussions](https://github.com/z3rco/satim-sdk/discussions) | Usage questions, integration help, ideas |
| [GitHub Issues](https://github.com/z3rco/satim-sdk/issues) | Bug reports and concrete feature requests |
| [Security Advisories](https://github.com/z3rco/satim-sdk/security/advisories/new) | Vulnerabilities — never open a public issue for these |

## Before opening an issue

1. Search [existing issues](https://github.com/z3rco/satim-sdk/issues) and [discussions](https://github.com/z3rco/satim-sdk/discussions) — the question may already be answered.
2. Check the [API reference](https://z3rco.github.io/satim-sdk/) and module READMEs under `src/`.
3. Verify you are on the [latest release](https://github.com/z3rco/satim-sdk/releases).

## SATIM gateway support

For issues with the SATIM gateway itself (credentials, terminal configuration, settlement, CIBWeb access), contact **SATIM directly**. This SDK is an independent open-source project and has no affiliation with SATIM or the CIB interbank network.
